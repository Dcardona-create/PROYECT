# Evidencias visuales — A2 Diseño

Esta carpeta reúne las capturas de los bocetos, wireframes y mockups de HOSTLOCK para contextualizar la documentación de diseño.

Las imágenes representan el diseño de referencia, no resultados de un sistema desplegado.

## Convención de nombres

Utilizar nombres en minúsculas, sin espacios ni tildes, indicando tipo, pantalla y dispositivo. Conservar la extensión real del archivo.

Ejemplo: `mockup-servicios-escritorio.jpg`.
