# Aplicativos a utilizar

## Virtualización

- **Proxmox VE:** plataforma para crear y administrar máquinas virtuales y contenedores.

## Redes

- **ISC-DHCP:** asignación automática de direcciones IP.
- **Pi-hole:** servicio DNS y filtrado de dominios.
- **iptables:** configuración de reglas de filtrado y seguridad de red.

## Hosting y aplicación

- **Nginx:** servidor web para publicar la aplicación.
- **MySQL:** base de datos del proyecto.
- **HTML y CSS:** estructura y diseño de la aplicación web.

## Seguridad SOC

- **Wazuh Server y Agents:** centralización, detección y análisis de eventos.
- **Suricata IDS:** detección de amenazas en el tráfico de red.

## Monitorización y blockchain

- **Prometheus:** recopilación de métricas.
- **Grafana:** visualización de métricas mediante paneles.
- **Python y Bash:** automatización de tareas.
- **Web3:** interacción con la blockchain.
- **Ethereum Testnet:** red de pruebas para desplegar el Smart Contract.
