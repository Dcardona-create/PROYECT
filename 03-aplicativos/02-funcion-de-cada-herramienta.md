# Función de cada herramienta

## Proxmox VE

Proxmox permite crear y administrar máquinas virtuales. Será la base de la infraestructura del proyecto y permitirá separar la red de gestión de la DMZ.

## ISC-DHCP

ISC-DHCP asignará direcciones IP automáticamente a los equipos de la red, facilitando la configuración y evitando errores manuales.

## Pi-hole

Pi-hole actuará como servidor DNS y permitirá bloquear dominios no deseados, mejorando el control y la privacidad del tráfico DNS.

## iptables

iptables permitirá crear reglas para controlar qué tráfico puede entrar, salir o moverse entre las diferentes redes del proyecto.

## Nginx

Nginx publicará la aplicación web y podrá utilizarse para proteger y gestionar el acceso a los servicios alojados.

## MySQL

MySQL almacenará la información necesaria para la aplicación web, como usuarios, registros o datos relacionados con los servicios.

## Wazuh

Wazuh centralizará los eventos de seguridad, analizará los logs y generará alertas cuando detecte actividades sospechosas.

## Suricata

Suricata analizará el tráfico de red y permitirá detectar posibles ataques o comportamientos anómalos.

## Prometheus y Grafana

Prometheus recopilará métricas de la infraestructura y Grafana las mostrará en paneles visuales para facilitar la monitorización.

## Python, Bash y Web3

Python y Bash se utilizarán para automatizar tareas. Web3 permitirá interactuar con la blockchain y enviar información al Smart Contract.

## Ethereum Testnet

Ethereum Testnet será la red de pruebas donde se desplegará el Smart Contract y se registrarán las alertas críticas.
