# Seguridad web y ataques

## Seguridad web

La seguridad web consiste en proteger aplicaciones, servidores y datos frente a ataques que pueden comprometer su disponibilidad, integridad o confidencialidad.

En este proyecto se protegerá una aplicación web alojada con Nginx y conectada a una base de datos MySQL.

## Ataques de inyección SQL

La inyección SQL es un ataque que aprovecha entradas maliciosas para manipular consultas realizadas a una base de datos.

Puede permitir a un atacante consultar, modificar o eliminar información si la aplicación no valida correctamente los datos introducidos por el usuario.

## Ataques DoS

Un ataque DoS, o *Denial of Service*, busca saturar un servicio para que los usuarios legítimos no puedan acceder a él.

En este proyecto se realizará una simulación controlada para comprobar cómo el sistema detecta y responde ante este tipo de incidente.

## Función en el proyecto

- Comprobar la detección de ataques por parte de Wazuh y Suricata.
- Analizar las alertas generadas durante las pruebas.
- Seleccionar incidentes críticos para su registro en blockchain.
- Validar la trazabilidad del sistema.
