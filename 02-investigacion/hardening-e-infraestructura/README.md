# Hardening, Proxmox e iptables

Estado: borrador inicial conservado para revisión técnica y ampliación de fuentes.

[Volver al cuadro de investigaciones](../README.md)

## Hardening

El borrador propone reducir servicios innecesarios, limitar permisos y accesos y aplicar configuraciones seguras. Contempla guías CIS e INCIBE, Lynis y Docker Bench como recursos para estudiar auditorías y seguridad de sistemas y contenedores.

## Proxmox VE

Se prevé crear y administrar máquinas virtuales y contenedores para organizar la red de gestión, DMZ, SOC y servicios web. La separación efectiva deberá diseñarse y validarse.

## iptables

Se investigará el filtrado de tráfico en Linux: permitir, bloquear y redirigir conexiones mediante reglas.

## Función prevista en el proyecto

- Hardening: reducir superficie de ataque y reforzar servidores.
- Proxmox: administrar la infraestructura virtualizada.
- iptables: controlar tráfico entre redes y servicios.

## Puntos para investigar

- Guías CIS e INCIBE.
- Auditorías con Lynis.
- Seguridad de contenedores Docker y Docker Bench.
- Creación de máquinas virtuales en Proxmox.
- Reglas básicas y avanzadas de iptables.
- Segmentación de red y DMZ.
