## Blockchain

El borrador contempla una estructura de registros encadenados distribuida para aportar trazabilidad a los eventos críticos. Se utilizará una red de pruebas de Ethereum, pendiente de seleccionar, no la red principal con fondos reales.

## Contratos inteligentes

Se prevé desarrollar un Smart Contract que gestione el registro o las pruebas de integridad de los eventos seleccionados. El formato exacto y los datos que se publicarán siguen pendientes.

## Notarización de alertas

La propuesta busca aportar una evidencia adicional que permita comprobar la integridad de los registros de seguridad. Deben investigarse los límites de las marcas temporales, la confidencialidad y el vínculo entre el evento original y la prueba publicada; no se garantiza por ello la veracidad del evento.

## Función prevista en el proyecto

- Notarizar eventos críticos seleccionados del SOC.
- Facilitar trazabilidad y auditoría.
- Detectar cambios posteriores mediante pruebas de integridad.
- Complementar las evidencias de Wazuh y Suricata.

## Puntos para investigar

- Ethereum, Mainnet y Testnet.
- Smart Contracts y Solidity.
- Integración con Web3.
- Registro y consulta de eventos.
- Selección de datos, hashes y límites del mecanismo.
