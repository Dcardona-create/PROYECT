# Prometheus, Grafana y Nginx

## Prometheus

Prometheus es una herramienta de monitorización que recopila métricas de sistemas, servicios y aplicaciones. Permite consultar datos, generar alertas y analizar el rendimiento de la infraestructura.

## Grafana

Grafana es una plataforma de visualización que permite crear paneles interactivos con datos procedentes de Prometheus y otras fuentes.

En este proyecto, Grafana permitirá visualizar métricas como el uso de CPU, memoria, red, estado de servicios y actividad de seguridad.

## Nginx

Nginx es un servidor web de alto rendimiento. También puede actuar como proxy inverso, equilibrador de carga y elemento de protección para servicios web.

## Función en el proyecto

- **Prometheus:** recopilar métricas de las máquinas virtuales y servicios.
- **Grafana:** mostrar paneles visuales con el estado de la infraestructura.
- **Nginx:** publicar la aplicación web y proteger el acceso a los servicios.
